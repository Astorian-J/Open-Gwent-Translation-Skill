# Translation Correction Guide

Mandatory rules for Gwent article translation. Apply these after initial draft.

## 1. Terminology Swaps (Always Fix)

| Wrong | Right | Notes |
|-------|-------|-------|
| 费用/消耗 (formal provision context) | 人口 | Exception: "4费战士", "低费铜卡" allowed in casual context |
| 高费/低费 (formal) | 高人口/低人口 | |
| 出场率 | 登场率 | |
| 协同效应 | 康博 / 配合 / 协同配合 | Technical: 协同配合, card review: 康博, general: 配合 |
| 惩罚卡牌 | 解场卡 | |
| 修血 | 蹭血 | |
| 站住/存活 | 撑过 | Refers to surviving |
| 获得利润 | 赚翻 / 获得收益 | |
| 滤牌 | 抽滤 | |
| 力量/强度 (unit) | 战力 | |
| 未被解掉 | 对手不管她 | Active voice |
| 调整回 | 回调到 / 改回去 | |

## 2. Concept Distinctions

### base power != full health
- "base power" = 基础战力（card-printed number）
- "heal to full / back to full health" = 回满血（in-game health status）
- Do NOT translate "heal back to full" as "治愈回基础战力"

### expensive != high provision
- "expensive removal" = 昂贵的解场卡
- Never use "高费" — "费" in Gwent context means provision

### unanswered != untouched
- "if left unanswered" = 如果对手不管她
- Not "如果未被解掉" (passive, no subject)

## 3. Sentence Structure

- Long sentences → 2-3 short Chinese sentences
- Chinese brackets 「（）」not English ()
- Dash allowed for supplementary clauses
- Passive → active voice
- Conclusion at paragraph end, short and punchy

## 4. Oral Verbs (Mandatory)

| Wrong | Right |
|-------|-------|
| 加入 | 塞进 |
| 打出（节奏卡） | 拍下 |
| 诱出 | 骗出 |
| 移除/解掉 | 处理掉 |
| 获利 | 赚翻 |
| 站住/存活 | 撑过 |
| 未被解掉 | 对手不管她 |
| 调整回 | 回调到 |

## 5. Number Rules

- Always Arabic numerals: 5点, 12人口, R3, 4P
- Never Chinese numerals: 五点, 十二人口

## 6. "X for Y" Format

- X = power, Y = provision
- Output: "Y人口X战力"
- Example: "6 for 5" → "5人口6战力"
- Warning: do NOT output identical numbers (e.g., "5人口5战力" means you reversed or duplicated)

## 7. Parentheses Consistency

- Body text uses 人口 → parentheses must also use 人口
- Allow abbreviation: body 人口, parentheses "5P" acceptable
- Never: body 人口, parentheses "费"

## 8. Error Examples

| Wrong | Right | Issue |
|-------|-------|-------|
| 我们就能将她治愈回基础战力 | 这样我们就能把她治疗回满血 | base power vs full health |
| 热浪等高费的惩罚卡牌 | 像热浪这样昂贵的解场卡 | expensive vs high-fee |
| 如果未被解掉，她将在自残卡组中成为巨大的威胁 | 如果对手不管她，她就会在自残群岛卡组里变成一个巨大的威胁 | passive vs active |
| 较高的基础战力让她至少能站住两个小局 | 高基础战力能帮她至少撑过两轮 | survive wording |
| 这张卡的费用是12，配合其他卡牌能获得利润 | 这张卡要12人口，配合其他牌直接赚翻 | oral tone |
| 她能在长局中持续修血，出场率也很高 | 她能在长局里一直蹭血，登场率也超高 | terminology + tone |
