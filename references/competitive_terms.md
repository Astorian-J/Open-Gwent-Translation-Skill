## Deck Name Translation Rules (卡组名称翻译规则)

### 已知社区别称
优先使用本文件及 `cn_fuzzy_fixes.md` 中记录的社区别称。

### 未知卡组名（无社区别称时）
若原文为 **领袖 + 卡牌/机制** 的组合形式，按以下规则直译：

**格式：卡牌/机制名词 + 领袖名 + 阵营简称**

| 阵营 | 英文 | 简称 |
|------|------|------|
| 北方领域 | Northern Realms | 北 |
| 史凯利格 | Skellige | 岛 |
| 怪兽 | Monsters | 怪 |
| 尼弗迦德 | Nilfgaard | 帝（或尼） |
| 松鼠党 | Scoia'tael | 松 |
| 辛迪加 | Syndicate | 迪迦 |

**示例：**
- `Blaze of Glory Eist Warriors` → 荣耀圣焰 + 征战 + 岛 = **荣耀圣焰征战岛**（但社区实际叫"荣耀圣焰征战"）
- `Patricidal Fury Warriors` → 鸣镝动怒 + 战士 + 岛 = **鸣镝动怒战士岛**（社区叫"鸣镝动怒征战"）

**注意**：此规则仅作为无社区别称时的fallback。若用户提供了社区叫法，以社区叫法为准。
