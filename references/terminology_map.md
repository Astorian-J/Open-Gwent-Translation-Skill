# Terminology Quick Map

## Core Concept Distinctions (Highest Priority)

| English | Chinese | Notes |
|---------|---------|-------|
| provision | 人口 | Deck-building cost. Formal: always "人口". Casual: "5P" or "4费战士" allowed, consistent within article |
| power | 战力 | Unit strength value |
| cost/fee (SY Tribute) | 费用/献金 | In-game payment, Syndicate only |
| stat / card stat | 卡位 | Card numerical attributes |
| deck-building cost | 人口 | Same as provision |

## Number Formulas

- "X for Y" → X=power, Y=provision → Output "Y人口X战力"
- Example: "8 for 8" → "8人口8战力"
- Example: "6 for 5" → "5人口6战力"
- Example: "1 for 7" → "1人口换7战力"
- Abbreviation allowed: "5P", "4费" (casual only, consistent within article)
