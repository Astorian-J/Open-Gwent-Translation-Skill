# Reverse Terminology Map (中文 → 英文)

For translating Chinese Gwent articles into English.

|---------|---------|-------|

| 解场卡 | removal card | |
| 蹭血 | ping damage | |

| 康博 | combo/synergy | Community slang, use "combo" in formal English |

## Number Formulas (反向)

- "Y人口X战力" → "X for Y" (X=power, Y=provision)
- Example: "5人口6战力" → "6 for 5"
- Example: "8人口8战力" → "8 for 8"

## Style Notes for CN → EN

### Sentence Structure
- Short Chinese sentences → Combine into flowing English prose
- Active voice in Chinese → Maintain active voice in English
- "如果对手不管她" → "If left unanswered" (preserves community phrasing)

### Tone Mapping
- Bilibili casual tone → Casual but natural English, not stiff
- "这卡强度不太行" → "This card's pretty underwhelming"
- "直接赚翻" → "generates massive value"
- "来了一刀" → "got nerfed" / "took a hit"

### Abbreviations
- 5P → "5-provision" or "for 5" (context-dependent)
- 4费战士 → "4-cost warrior" (casual only)

### Punctuation
- Chinese brackets 「（）」→ English parentheses ()
- Chinese colon "：" → English colon ":"
