# Style Reference

Translation style modeled after Metallic Danny BC proposal (2026-05-30, verified by 进).

## Good Translation Patterns

### Opening - Community Tone
> 和往常一样，这份名单是由我们社区超过 200 名成员共同编制的，大家积极提出了自己的方案并参与了问卷调查。在讨论过程中，社区内部以及各社区之间也剔除了一些建议。

- Direct, warm community voice
- "和往常一样" as natural opener
- Active verbs: 编制, 提出, 参与, 剔除

### Faction Analysis - Objective
> 这个赛季，我们尝试将重心放在了北方领域和尼弗迦德上。因为北方几乎被各个社区大幅削弱了，而尼弗迦德的整体处境即使在安娜·亨莉叶塔加强之后依然非常糟糕。

- Factual, no hedging
- "整体处境...非常糟糕" — strong but not exaggerated

### Card Analysis - Alternative Option
> 目前的构造体卡组并不使用这张卡，所以这与其说是一次全面的增强，不如说是提供了一个替代选项。这张卡本身其实已经挺不错的了，但需要让它更亮眼一点。

- "与其说...不如说" structure for nuanced evaluation
- "让它更亮眼一点" — vivid, understated

### Card Analysis - Nerf Evaluation
> 上个赛季这张卡已经被削弱过一次了，但他依然非常强力。他活跃在史凯利格最强的战士和弃牌鸟岛卡组中，并且经常配合佛卡夏被过度利用。这次会稍微降低一点他的强度。

- Acknowledges history
- Community slang: "鸟岛" for GN Shupe deck
- "过度利用" — measured criticism

### Card Analysis - Tactical Reasoning
> 我们认为，与其提高克拉肯的战力，不如直接削弱罗盘，这样就不会伤及下雨卡组了。

- "与其...不如" for comparison
- Clear cause-effect chain

### Card Analysis - Mechanic Explanation
> 这是对通过反复利用工程师、摧毁对手场面来运作的卡组的一种直接削弱。我们社区的成员认为，这种比较赖皮的组合技应该配合「卫士」的改动一起进行。

- "赖皮的组合技" — abusive combo in community slang
- Bilibili tone: colloquial but precise

## Style Features to Preserve

- **"赖皮的组合技"**: abusive combination → colloquial, Bilibili player tone
- **"登场率其实很低"**: always "登场率", never "出场率"
- **"改回去"**: revert → more colloquial than "回调"
- **"没人带"**: is almost not used → concise and punchy
- **"让它更亮眼一点"**: needs to be highlighted → vivid
- **"强度不太行"**: not very effective → understated criticism
- **"差点"、"可以接受"**: light, dismissive tone
- Community terms: 气宗, 孽鬼店店, 互口岛 — accurate slang

## Sentence Patterns

| English Pattern | Chinese Pattern | Example |
|-----------------|-----------------|---------|

| is almost not used | 没人带 | Almost no one uses this → 这卡没人带 |
| needs to be highlighted | 让它更亮眼 | It needs more attention → 得让它更亮眼一点 |
| slightly reduce | 稍微降低一点 | Slightly reduce power → 稍微降低一点强度 |

## Figurative Language & Tone Judgment (修辞与语气判断)

Gwent community writing is heavy on metaphor, hyperbole, sarcasm, and trash-talk.
Translate the **intent and force**, not the literal words. Do not flatten irony
into sincerity — that is the most common way these translations go bland.

### Rules
1. **识别 first.** Before translating a sentence, judge: is this literal, or
   figurative (比喻 / 夸张 / 反讽 / 嘲讽 / 习语)? If figurative, the words are a
   vehicle for an attitude, not the meaning itself.
2. **译意图，不译字面.** Keep the image when Chinese has an equivalent-register
   counterpart; otherwise swap the vehicle for one that lands in Chinese. Do not
   translate a dead metaphor word-for-word when it reads awkwardly.
3. **绝不抹平语气.** Sarcasm stays sarcastic, mockery stays biting, hyperbole
   stays big. "guess what" → 你猜怎么着 (not "我告诉你"); a dismissive tone stays
   dismissive; "sweet spot" keeps its "just-right" feel, not a dry "该去的位置".

### Examples (from a real BC discussion)

| English (figure) | Type | Bad (literal / flat) | Good (intent kept) |
|---|---|---|---|
| "ng siege on steroids" | hyperbole | "围攻体系…类固醇" | "围攻体系…打了鸡血般的加强版" |
| "massively loud gameplay design" | metaphor | "太大声的设计"（生硬） | "存在感太强 / 喧宾夺主的设计" |
| "the sweet spot for it" | idiom | "该去的位置"（被抹平） | "刚刚好的最佳点 / 甜点位" |
| "or it sinks" (support rate) | metaphor | "或者它下沉" | "还是沉底" ✓ |
| "guess what, I lose…" | sarcasm | "我告诉你，我输掉…" | "你猜怎么着，我就解不掉了" ✓ |
| "All I hear is someone who…" | dismissive | "我听到的只是某人…" | "我听到的就是某些人…（想保住 2-0）" ✓ |
| "enablers that make it toxic" | metaphor (slang) | "让它有毒的" | "让 tutor 变得有毒的配合牌" ✓ |

### Swap the vehicle when the literal doesn't land
- **"loud design"** → "存在感太强 / 喧宾夺主"（别照搬"大声"，中文里生硬）
- **"on steroids"** → 幽默场合用"打了鸡血般"，中性场合用"加强版 / 超强版"
- **"sweet spot"** → 保留"刚刚好"的感觉，别翻成干巴巴的"位置"
- **"braindead / one-trick pony"** → "无脑 / 一招鲜"（保留贬义比喻的力度）

## Balance Change Direction（平衡调整增强削弱判断）

翻译平衡调整（patch/buff/nerf）内容时，必须准确理解增强/削弱方向。昆特牌设计特殊，方向不一定按数值直觉。

**方向词：**
- `buff / buffed / buffs / buffing` = **增强**（变强）
- `nerf / nerfed / nerfs / nerfing` = **削弱**（变弱）
- `change / adjust / tweak / rework` = 改动（中性，别硬补方向）

**增强/削弱判断规则（昆特牌特殊设计）：**
- **一般单位**：战力 +1 = 增强，战力 −1 = 削弱；人口 −1 = 增强，人口 +1 = 削弱。
- **间谍单位（Disloyal / 不忠，部署在对方场上）**：战力方向反 —— 战力 −1 = 增强，战力 +1 = 削弱（间谍战力算对方的，减战力对自己有利）。
- **领袖卡（Leader，无战力，只改人口）**：人口方向反 —— 人口 +1 = 增强，人口 −1 = 削弱（领袖人口高 = 能带更多牌）。

**原则：**
- 原文明确写 `buff`/`nerf` → 照原文方向译。
- 原文只给数值变化 → 按上述规则理解改动方向，翻译相关描述时方向要一致，**不要翻反**。
- 原文没明说且无法判断 → 照翻事实，不要硬补方向。

**示例：**
- `「Stefan Skellen」(间谍) nerf to 9 power` → 削弱到 9 战力（间谍减战力 = 对自己更有利？不，原文已说 nerf，照原文方向）
- `「Force of Nature」(领袖) +1 provision` → 增强（领袖人口方向反，加人口 = 增强）
- `「Geralt」to 6 power` → 只给数值，按一般单位规则理解为增强方向

## Markdown Format Preservation（Markdown 格式保留）

原文是 Markdown 格式时，译文必须 **1:1 保留原文的 Markdown 结构和标记**。只翻译文字内容，绝不改动任何标记符号、缩进、换行、空行。

**逐行对应：**
- 原文每一行对应译文一行，不增不减行，不合并/拆分，不改换行与空行。

**标记保留规则：**
- **标题**：`#` 数量必须一致（`##` 还是 `##`），不改层级。
- **列表**：`-` / `*` / `+` 标记和缩进必须一致，列表项数量一致。
- **表格**：`|` 列数必须一致，表头分隔行（`|---|`）原样保留，只翻译单元格文字。
- **粗体/斜体**：`**xxx**` / `*xxx*` 标记保留在对应文字上。
- **引用/代码**：`>` 引用标记保留；`` `xxx` `` 和 ` ``` ` 围栏保留，代码内容不翻译。
- **链接/分隔线**：`[文字](url)` 只翻译文字部分，url 不动；分隔线 `---` 保留。

**示例：**
- `| Card | Power |` → `| 卡牌 | 战力 |`（列数、`|`、`---` 全保留）
- `- **Geralt**: strong` → `- **杰洛特**：很强`（`-` 和 `**` 保留，文字翻译）
- `## Tier List` → `## 梯队表`（`##` 保留）

## Term Variants (术语变体识别)

原文卡名/术语常有变体, 一律按 Term Lock Table 的规范译名翻译, 别脑补别字面直译:
- 标点变体: Geralt Aard / Geralt:Aard = Geralt: Aard
- 拼写/typo: Kaedweni Cavalary = Kaedweni Cavalry
- 重音变体: Schirru = Schirrú
- 简称/缩写: GN = 黄金孽鬼像 (别和 NG=尼弗迦德 搞混)
- 别称: 鸟岛 = Shupe deck

Term Lock Table 的 Aliases/Abbrevs 列是已知变体, 照此对译名. 遇到不认识的卡名词, 优先匹配表中相近条目, 不要自创新译名.
